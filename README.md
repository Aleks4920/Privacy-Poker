# Privacy Poker

Browser-based educational game teaching informed consent and data minimisation, built as a project for a Usable Security and Privacy course.

## Concept

Players wager personal data as poker chips across multiple rounds, each representing a real-world service category (weather, social network, e-commerce, navigation, fitness, news, dating app, smart home). Each service splits its data demands into required and optional categories, making the usually invisible cost of agreeing to data collection explicit.

## Run it

Open index.html in any modern browser. No installation required.
